# RH AI DJ Lab

Отдельный экспериментальный автономный DJ-сайт. Не связан с RH—MUSIC: собственный фронтенд, собственный аудиодвижок и отдельный Cloudflare Worker.

## Что умеет

- поиск треков через Zvuk и (при доступном client id) SoundCloud;
- добавление треков в «Мою музыку» одним нажатием;
- обычный плеер;
- кнопка **Mix**;
- двухдековый Web Audio движок;
- анализ BPM, ключа, энергии, вокала, intro/outro и фраз;
- автоматический выбор следующего трека;
- подготовка следующего дека;
- кроссфейд с bass swap и EQ;
- несколько переходов подряд.

## Архитектура

```text
public/engine.js   — Deck A/B, анализ, планировщик, переходы
public/app.js      — поиск, библиотека, плеер, Mix
worker/src/index.js — прокси Zvuk/SoundCloud, токены только в secrets
```

Аудио Zvuk проксируется только в MID 128 kbps. SoundCloud использует progressive MP3, если он доступен; HLS-only треки не подменяются выдуманным потоком.

## Токены

В Worker:

```text
ZVUK_TOKEN
SC_CLIENT_ID
```

В коде и публичных файлах токенов нет.

## Ограничения

- SoundCloud client id может быть отозван — поиск/поток тогда недоступен, интерфейс это не скрывает;
- анализ выполняется в браузере, поэтому первый трек анализируется после запуска;
- ключ определяется упрощённым chroma-анализом;
- это эксперимент, а не готовый продукт для всех браузеров.
